DAPPIWZ STORE — FULL FRONTEND

Cara menjalankan:
1. Buka index.html di browser.
2. Ganti semua nomor 6280000000000 di index.html dan script.js dengan nomor WhatsApp admin.
3. Produk dan harga ada di PRODUCTS pada script.js.
4. Ganti assets/logo.png jika ingin memakai logo lain.

Fitur:
- Responsive desktop/mobile
- Header sticky
- Search produk
- Filter kategori
- Product detail modal
- Keranjang localStorage
- Checkout form
- Redirect order ke WhatsApp
- Promo
- Cara order
- FAQ
- Artikel
- Footer

Catatan:
Ini adalah frontend yang sudah interaktif. Untuk pembayaran otomatis, login akun, database, panel admin, dan status transaksi real-time diperlukan backend/database/payment gateway.
