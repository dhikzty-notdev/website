# Dappiwz Store

Website statis sederhana untuk Dappiwz Store.

## Isi
- `index.html` — halaman utama
- `style.css` — desain/responsive
- `script.js` — status OPEN/CLOSED WIB, menu mobile, dan tombol pembelian WhatsApp
- `assets/logo.png` — logo Dappiwz Store

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua isi folder ini.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. GitHub akan memberikan alamat website Pages.

Status toko mengikuti waktu **Asia/Jakarta (WIB)**:
- 10.00–22.59 = `[OPEN]`
- 23.00–09.59 = `[CLOSED]`

Tombol produk otomatis membuka WhatsApp Owner dengan pesan:
`Hai kak saya mau beli (barang yang di pencet), tolong konfirmasi pembayarannya yaa kak...`
